# Ferrum — сайт (v2)

Статический сайт: `HTML + CSS + JS`, без сборки и зависимостей. Работает локально.

## Как открыть
- Просто двойной клик по `index.html`, **или**
- Локальный сервер (лучше для шрифтов/кэша):
  ```bash
  python -m http.server 5173
  ```
  затем открыть `http://localhost:5173`

## Структура
```
index.html        # разметка, все секции по wireframe
css/styles.css    # дизайн-система «Точная линия» (токены + компоненты)
js/main.js        # reveal, счётчики, навбар, меню, FAQ, форма
assets/img/       # сюда кладём реальные фото
```

## Как заменить плейсхолдеры на реальные фото
Каждый фото-блок помечен `data-media`. Чтобы поставить фото — вложите `<img>` внутрь блока:

```html
<!-- было -->
<div class="card__media" data-media data-label="НАВЕСЫ · ФОТО"></div>

<!-- стало -->
<div class="card__media" data-media data-label="НАВЕСЫ · ФОТО">
  <img src="assets/img/naves-1.jpg" alt="Навес для автомобиля" />
</div>
```
`<img>` автоматически ложится поверх плейсхолдера (`object-fit: cover`). Ничего в CSS менять не нужно.

**Рекомендации по фото:** тёплый естественный свет, реальные работы, единая цветокоррекция. Формат WebP/JPG. Ширина hero ≥ 2000px, карточки ≥ 1000px.
